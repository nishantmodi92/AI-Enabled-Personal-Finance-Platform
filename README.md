# AI-Enabled-Personal-Finance-Platform

Modern Android finance platform demonstrating expense management, budgeting, financial insights and AI-enab

Key Features
. Expense tracking
. Budget management
. Transaction workflows
. Financial insights
. Local persistence
. REST API integration
. AI-assisted insights
. Context-aware AI interactions

Impact
. Demonstrates practical AI integration in Android
. Separates AI services from core business logic
. Combines local data with remote services
. Designed for scalable feature development

Tech Stack
Kotlin, Jetpack Compose, Clean Architecture, MVVM, Room, Retrofit, OkHttp, Coroutines, Flow, Firebase, Gemini API, LLM APIs
